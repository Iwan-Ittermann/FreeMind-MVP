# Memory: ui/navigation/floating-controls-v3
Updated: 2026-03-06

All floating buttons (settings, help, opinions, chats) have been removed from the home page. Navigation is now unified into a single burger menu (☰) in the header's right side. The burger opens a MainMenu sheet with: About, Tutorial, Settings (nested sheet with Login Secret, Change Opinion placeholder, Language), All Opinions, Your Requests (separate RequestsSidebar), Your Chats, and Logout. The Add Opinion CTA remains as a full-width pill button below the graph. Graph labels use rolling rotation: 5 visible at a time, swapping 2 every 3 seconds. Current user's node and highlighted nodes always show labels.
